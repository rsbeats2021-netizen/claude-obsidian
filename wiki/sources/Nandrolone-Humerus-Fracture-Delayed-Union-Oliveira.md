A veterinary case report (read via Portuguese/English abstract) describing nandrolone decanoate used to stimulate healing in a delayed-union humerus fracture — a fourth or fifth distinct context (alongside achondroplasia growth, reproductive toxicity, telomere elongation, and muscle wound healing) for the same drug's varied applications already cataloged in this domain.
