# Figure Licensing Audit — `.raw/Studies`

Which papers in the library have figures that can legally be reused in
**monetised** short-form content (the channel sells an ebook and consultations,
so everything counts as commercial use).

Scanned 416 PDFs on 2026-09-03. Re-run before each content project — the
library grows.

## Rules

| Licence | Commercial reuse | Notes |
|---|---|---|
| CC-BY, CC-BY-SA, CC0/PD | ✅ yes | Attribution required (except CC0) |
| CC-BY-**NC**, CC-BY-**NC-ND** | ❌ no | Non-commercial only — off-limits for this channel |
| All rights reserved | ❌ no | Owning the PDF ≠ a licence to republish |
| Unknown | ⚠️ verify | Scanner found no licence string; check the paper itself |

ResearchGate / Sci-Hub copies carry no licence. Where you got the file does not
change the underlying rights.

## How to re-run

```bash
python3 scripts/scan-figure-licences.py
```

Extraction recipe for a cleared figure (journal figures are usually vector, so
raster extraction returns nothing — render and crop instead):

```python
import pymupdf
d = pymupdf.open(path)
pix = d[page].get_pixmap(dpi=600, clip=pymupdf.Rect(x0, y0, x1, y1))
pix.save(out)
```
