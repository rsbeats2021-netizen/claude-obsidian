# Neuroregenerative Effect of Oxandrolone in Charcot-Marie-Tooth Disease (Bianchi & Marbini 2015)

A single case report finding oxandrolone — the same anabolic androgen central to this domain's pediatric growth-promotion literature via [[Oxandrolone-Pediatric-Growth-Disorders-Review|Soliman et al. 2025]] and [[Growth-Promotion-Short-Normal-Child-Thesis|Stirling 1994]] — apparently produced a neuroregenerative effect in a patient with Charcot-Marie-Tooth disease, a hereditary peripheral neuropathy. This is an entirely novel tissue application (peripheral nerve) unrelated to oxandrolone's growth-plate/muscle mechanisms.

> [!gap] Single case report, low evidentiary weight; no proposed mechanism for how an androgen-receptor-mediated drug would affect peripheral nerve regeneration specifically.

## Relevance to This Domain

An unusual tissue-context outlier for [[Testosterone]]'s oxandrolone thread — worth noting as a curiosity but not integrated into the domain's growth-plate mechanistic framework given the single-case, low-confidence evidence and unclear mechanism.
